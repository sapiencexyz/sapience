# Contracts & Addresses

All deployed addresses and ABIs are available in the SDK:

```bash
npm install @sapience/sdk
```

```typescript
import { contracts } from '@sapience/sdk/contracts';
import { predictionMarketAbi, liquidityVaultAbi } from '@sapience/sdk/abis';

const escrow = contracts.predictionMarket[5064014].address;
const vault  = contracts.passiveLiquidityVault[5064014].address;
```
